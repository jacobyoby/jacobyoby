# jacobyoby profile

Jacob's personal GitHub profile: `README.md` renders at https://github.com/jacobyoby the
moment it reaches `main`. There is no build, test, or deploy step.

- `README.md` is the page. `assets/` holds its images; `docs/ARTWORK.md` records how the
  workshop illustration was made.
- Every pushed change is public at once, so a push needs Jacob's yes.
- Each factual claim (bug numbers, dates, project status) must match its linked source.
  Check the link before changing the claim.
- Keep `width` and `height` on images and alt text on every image.
